# Security Policy

Speed Download is in early development and does not yet provide a released product or supported binary.

## Reporting a vulnerability

Please do not report security issues in public issues. Use GitHub's **Report a vulnerability** feature for this repository when it is available. Include affected commit or version, impact, and reproducible steps; omit real credentials and private data. If private reporting is unavailable, contact the repository maintainer through a verified private channel before publishing details.

There is currently no response-time commitment. Do not test against systems or accounts you do not own or have permission to assess.
