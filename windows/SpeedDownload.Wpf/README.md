# Speed Download for Windows

The Windows desktop client uses WPF and communicates with the bundled Zig engine through a per-user named pipe. Extract the entire ZIP, then run `SpeedDownload.exe`. Keep `speed-download.exe` beside the client so it can start the engine when needed.

The client supports adding HTTP downloads, viewing progress, pausing and resuming jobs, search, and a transfer inspector. It is a self-contained .NET publish, so the ZIP does not require a separate .NET installation. The app has not been code signed.
